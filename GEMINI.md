# Gemini CLI project instructions

Use this repository as the WPEssential Checkout Impact Regression add-on project.

Before any work, read these files in order:

1. `AGENTS.md` — canonical contributor and AI rules.
2. `README.md` — product summary and current phase/status tracker.
3. `docs/DEVELOPMENT-PLAN.md` — detailed requirements, evidence, decisions, and task backlog.

Work only on a task whose dependencies are met. Preserve the documented product focus: before/after impact comparison across saved checkout scenarios. Separate verified facts from assumptions, cite official sources, and do not claim unsupported compatibility. Do not add product CLI commands or a CLI interface before final release. Update README status, progress, and dates only when evidence supports the change; report sources, completed criteria, blockers, and remaining work.

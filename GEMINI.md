# Gemini CLI project instructions

Use this repository as the WPEssential Checkout Impact Regression add-on project.

Before any work, read these files in order:

1. `AGENTS.md` — canonical contributor and AI rules.
2. `README.md` — product summary and current phase/status tracker.
3. `docs/DEVELOPMENT-PLAN.md` — detailed requirements, evidence, decisions, and task backlog.

Choose the highest-priority unblocked task and execute it. Resume prompts such as “continue”, “start”, “...”, and “?” resume the authorized project work; do not ask for another start message or return status in place of implementation. For each task implement, validate, package, and staging-test when its acceptance criteria require it and the authorized environment is safe. If one task is blocked, record its exact prerequisite and continue with independent tasks. Update backlog, evidence, and README together; push only verified checkpoints to authorized main. Follow AGENTS.md for the task-count progress formula and mandatory delivery loop. Phase 6 NO-GO blocks automated checkout replay/observation only. Preserve the before/after regression focus, cite official sources, make no unsupported compatibility claims, and add no product CLI before final release.

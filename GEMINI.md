# Gemini CLI project instructions

Follow `AGENTS.md` (canonical rules). Then read `README.md` and `docs/DEVELOPMENT-PLAN.md`, which is the source of truth for scope, decisions, backlog and the progress formula. Work on a branch and open a pull request; do not push to `main`. Resume prompts ("continue", "...", "?") resume the current task but never authorise external or irreversible actions.

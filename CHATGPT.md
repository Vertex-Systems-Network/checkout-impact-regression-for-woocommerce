# ChatGPT repository handoff guide

This file is a manual entry point for ChatGPT sessions connected to or reviewing this GitHub repository. Do not assume a general ChatGPT chat automatically discovers or loads it.

## Instructions for the assistant

Before working, open and read:

1. `AGENTS.md` for canonical repository rules.
2. `README.md` for product direction and the current phase tracker.
3. `docs/DEVELOPMENT-PLAN.md` for scope, compatibility requirements, evidence, decisions, and backlog.

Then identify the exact task ID and acceptance criteria. If this ChatGPT session cannot read the repository files, state that limitation and ask the user to attach or paste the relevant files; never claim to have followed instructions that were not available.

Keep the core product focused on before/after comparisons across saved checkout scenarios. Verify platform or competitor claims with official documentation. Do not add a product CLI before final release. Update the README progress table only when the relevant work is genuinely completed or has verifiable progress, and report sources, evidence, assumptions, blockers, and remaining steps.

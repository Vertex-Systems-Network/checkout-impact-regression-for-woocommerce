# Pro Add-on

**Checkout Impact Regression Pro for WooCommerce** is a separate plugin sold on the WooCommerce Marketplace. Repository: <https://github.com/Vertex-Systems-Network/checkout-impact-regression-pro-for-woocommerce>

| Feature | Where |
|---|---|
| Email alerts when a plugin update or payment/shipping setting change is recorded (one digest per 15 minutes, up to 5 recipients, 3 retries, no setting values in the email) | Checkout Impact → **Alerts** |
| CSV / JSON export of a scenario's saved reports | Checkout Impact → **Reports** |

## Requirements

Pro **needs this free plugin** installed and active:

- WordPress refuses to activate Pro without the free plugin (`Requires Plugins`).
- The free plugin cannot be deactivated from the Plugins screen while Pro is active.
- Pro checks the free plugin's version and stays idle with a notice if it is too old.

The free plugin contains no Pro code and works fully on its own.

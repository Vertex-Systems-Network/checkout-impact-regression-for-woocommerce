# Settings and Privacy

**WooCommerce → Checkout Impact → Settings**

- **Keep saved reports for (days)** – 7 to 365, default 30. Applies to reports saved afterwards.
- **Delete all Checkout Impact data when the plugin is deleted** – off by default. Deactivating never deletes data.

## Privacy

- No external services, tracking, remote assets or licence checks.
- Data lives in the plugin's own tables (`wp_wpecir_*`).
- Only users with `manage_woocommerce` can use the screen and REST API.
- WordPress personal data export/erase: the plugin exports and anonymises the user IDs it stores as scenario author or baseline approver.
- A suggested privacy-policy paragraph is added under *Settings → Privacy → Policy Guide*.

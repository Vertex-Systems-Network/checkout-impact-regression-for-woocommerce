# Checkout Impact Regression for WooCommerce

See what changed at checkout after a plugin update or a settings change. Save checkout **scenarios**, approve a known-good **baseline**, and **compare** shipping method, shipping cost, coupon, discount and payment methods field by field.

The plugin never places orders or runs checkout. You record what checkout shows (ideally on a staging copy) and the plugin stores and compares it.

## Requirements

WordPress 6.9+, PHP 8.2+, WooCommerce 10.8+. Tested on WordPress 7.1.4 with WooCommerce 11.2.2 on PHP 8.2, 8.3 and 8.4 (MariaDB 10.11 and SQLite).

The same help is built into the plugin: **WooCommerce → Checkout Impact → Docs**.

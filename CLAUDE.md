# Claude Code project instructions

@AGENTS.md

Before starting work, read `README.md` and `docs/DEVELOPMENT-PLAN.md`. Treat `AGENTS.md` as the canonical project rules and the development plan as the source of truth for product scope, status, decisions, and backlog.

For a bounded task, identify its task ID, phase, dependencies, and acceptance criteria from the plan. Do not begin implementation while the task is blocked by research or decisions. After work, report evidence and update the README tracker only when a real status change is supported. Do not add any CLI interface or commands to the product before final release.
